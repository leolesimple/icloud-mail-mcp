# Contributing

Thanks for your interest in icloud-mail-mcp.

## What's welcome

- **Bug reports** with a minimal reproduction, using synthetic messages. Never paste tokens, app
  passwords or real mailbox content.
- **Feature ideas** and questions, via [issues](https://github.com/leolesimple/icloud-mail-mcp/issues).
- **Security reports**, through the private channel described in [SECURITY.md](SECURITY.md).

## What isn't

The project is under [PolyForm Strict 1.0.0](LICENSE), which does not allow modifications or
derivative works. For that reason **pull requests with code changes are not accepted**. Typo and
documentation fixes are fine; open an issue first if in doubt.

## For reference

[`docs/development.md`](docs/development.md) (in French) explains how the project is built and
tested. Commits follow [Conventional Commits](https://www.conventionalcommits.org/), enforced by
commitlint and used by semantic-release.
